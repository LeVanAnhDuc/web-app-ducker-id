# SETTINGS — ngôn ngữ, giao diện, định dạng

- **REQ-SETTINGS-01** Tiếng Anh (không prefix) và tiếng Việt (`/vi`) được chuyển đổi từ user menu.
- **REQ-SETTINGS-02** Theme sáng, tối hoặc theo hệ thống được chọn từ user menu và được giữ lại.
- **REQ-SETTINGS-03** Ngày giờ hiển thị theo định dạng của locale đang dùng.
- **REQ-SETTINGS-04** Tính năng đã gỡ (Team) không để lại route hay mục điều hướng nào.
- **REQ-SETTINGS-05** Ngôn ngữ và giao diện đổi được cả khi chưa đăng nhập, từ user menu của trang công khai (vd `/login`).
