**Hạ tầng dùng chung nhiều module** (dọn DB, plant mã, seed phiên) nằm ở đây theo skill. Ducker ID chỉ lưu mã một lần
dưới dạng hash bcrypt nên test không đọc được mã thật: gọi endpoint _send_ thật rồi plant mã đã biết. Key layout bám
`server/src/constants/redis/store/index.ts` — test báo "invalid code" thì xem đó trước.

Redis là **Redis cloud** của server (`server/.env` → `REDIS_URL`), dùng chung với server dev: suite xoá `rate-limit:*`
và ghi key OTP trên đó. Không chạy suite khi một server Ducker ID khác (vd dev `:5000`) đang dùng cùng Redis — BullMQ
queue là theo Redis, không theo database.

**Quy tắc:** không import `pages/`, `components/`, `fixtures/`. URL datastore lấy qua `config/datastores.ts`, không tự
đọc `.env`. `accounts.ts` / `auth.ts` gọi API qua `api/` (đăng ký thật, để tài khoản giống hệt user thật). Chỉ ghi lên
tài khoản **throwaway**; dữ liệu seed dùng chung thì trả lại trong `afterEach`.
Chỉ thêm khi có test thật sự cần, không chép sẵn "để đó".
